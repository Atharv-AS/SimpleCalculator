# Simple Calculator – Java GUI Application

## 1. Project Overview

The Simple Calculator is a desktop-based GUI application developed using Java Swing. It performs basic mathematical operations through a simple and user-friendly graphical interface.

This project is developed as part of **CIE-2 Activity-6 – OOP GUI Application** for S.Y. B.Tech.

## 2. Objectives

- To develop a graphical calculator using Java.
- To understand Object-Oriented Programming concepts.
- To implement event handling using Java Swing.
- To perform basic arithmetic calculations.
- To create a simple and user-friendly interface.

## 3. Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **IDE:** Visual Studio Code
- **JDK:** Java Development Kit
- **Layout:** BorderLayout and GridLayout

## 4. Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Decimal number calculations
- Clear button (C)
- Delete button (DEL)
- Division by zero error handling
- Interactive graphical interface

## 5. OOP Concepts Used

| Concept | Implementation |
|---|---|
| Class | SimpleCalculator |
| Object | Calculator window object |
| Inheritance | JFrame |
| Interface | ActionListener |
| Method | actionPerformed() |
| Event Handling | Button click events |
| Encapsulation | Private variables and methods |

## 7. How to Run the Project

### Step 1: Install Java

Install JDK on your computer.

### Step 2: Open Project

Open the SimpleCalculator folder in Visual Studio Code.

### Step 3: Compile the Program

Open the terminal and execute:

```bash
javac SimpleCalculator.java
```

### Step 4: Run the Program

Execute:

```bash
java SimpleCalculator
```

The calculator GUI window will open.
